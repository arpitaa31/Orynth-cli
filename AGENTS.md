# Orynth Agent Guide

Orynth is an experimental Rust project. `BLUEPRINT.md` is the research and design source for future work.

Canonical implementation documents live under `docs/`, and implementation plans live under `plans/`. Future coding agents must read the relevant documentation before modifying architecture and must not silently invent architecture that contradicts canonical documents.

Significant architectural changes should be recorded in `docs/decisions/`. Keep `docs/STATUS.md` and `plans/CURRENT.md` accurate. Before claiming work complete, run tests, formatting, and Clippy.
