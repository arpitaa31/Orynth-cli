# Architecture Decisions

Status: canonical decision index.

Significant decisions record context, decision, alternatives, consequences, and status. The foundational boundary is recorded in ADR-0001.

- ADR-0043 records the projection-backed, read-only runtime inspector boundary
  for the initial Phase 8 TUI/app slice.
- ADR-0044 records event-derived semantic breakpoint scanning without live
  mutation or provider invocation.
- ADR-0045 records the explicit recorded-replay, fork-materialization, and
  projection-diff command boundary.
- ADR-0046 records the terminal-independent, read-only debug session boundary.
- ADR-0047 records durable, usage-safe configured-capacity transfers between
  existing agents.
- ADR-0048 records compact event-sourced failure memory without transcript
  copying or automatic retry suppression.
- ADR-0049 records evidence-based, read-only cache-aware model ranking with
  deterministic tie-breaking.
- ADR-0050 records bounded, read-only context freshness proprioception and
  explicit pressure flags.
- ADR-0051 records durable bounded specialist profiles and atomic child
  creation without conflating descriptive requirements with capability grants.
- ADR-0052 records deterministic threshold-based supervision promotion/pause
  with explicit candidates and user-pin protection.
- ADR-0053 records explicit replayable context archive/restore transitions
  without mutating state during freshness inspection.
- ADR-0054 records caller-supplied cache observation freshness at the routing
  boundary without inferring provider TTLs or physical cache state.
- ADR-0055 records explicit replayable context pin/unpin retention metadata
  without changing lifecycle or projection authority.
- ADR-0056 records bounded read-only context search and dependency inspection
  through recovered runtime projections.
- ADR-0057 records deterministic specialist profile selection without coupling
  descriptive matching to model routing or capability grants.
- ADR-0058 records durable agent cancellation as an identity-preserving terminal
  runtime transition.
- ADR-0059 records explicit bounded peer-consultation helpers over durable IPC
  question/answer envelopes.
- ADR-0060 records bounded manager observability for context, cache, artifacts,
  and per-agent failure-memory identifiers.
