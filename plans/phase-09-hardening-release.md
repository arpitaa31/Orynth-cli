# Phase 09: Advanced Orchestration

Status: preparation active.

After the core is reliable, add dynamic specialists, active supervision,
deterministic escalation triggers, peer consultation, speculative/shadow
workers, automatic promotion/demotion, cache-aware scheduling, and context
freshness policies. Durable budget transfer, bounded specialist profiles, and a
bounded event-sourced failure memory primitive are now implemented as
preparation for this phase; deterministic threshold-based promotion/pause is
implemented as a policy boundary, while broader policy-driven reactions,
semantic failure classification, cross-run memory, and the remaining
automation are still planned. Specialist profiles deliberately do not grant
capabilities or choose models by themselves. Each automation must remain
user-overridable and observable.
