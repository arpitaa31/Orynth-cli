# Phase 02: Runtime Core

Status: hardened baseline; remaining fault-injection work is deferred to hardening.

The current Phase 2 slices add an event-store contract, immutable sequencing, materialized run/task/agent/artifact reconstruction, terminal-transition validation, duplicate-event rejection, recorded replay, snapshot metadata, incremental event reads, in-memory content addressing, dependency-free filesystem event/blob adapters, a bundled SQLite backend, validated branch metadata for fork boundaries, versioned SQLite snapshot persistence, filesystem branch/snapshot sidecar persistence, child-run fork materialization, provider-backed child continuation, a backend-neutral atomic continuation persistence helper, an explicit local locking/durability policy, and the initial durable artifact write lifecycle. Filesystem adapters repair only incomplete final frames and reject complete checksum corruption; all three stores now provide event/artifact, branch-metadata, snapshot, prefix-fork, and batch-append paths. The filesystem event adapter is single-open under an OS advisory lock; same-hash artifact writes use per-artifact locks and synced temporary files; SQLite serializes writers with `IMMEDIATE` transactions, a busy timeout, and full synchronous durability. Fault-injection and directory-entry durability remain unverified.

Acceptance evidence is in thirty-seven deterministic tests in `orynth-event-store` and five in `orynth-agent`, including filesystem metadata persistence/recovery, interrupted multi-frame batch recovery, orphan-temp recovery, concurrent same-hash artifact writes, SQLite reopen, branch persistence/reopen, snapshot codec/load validation, fork materialization, provider-backed continuation, atomic batch append, filesystem lock release, concurrent SQLite writers, migration idempotence, duplicate-append atomicity, opaque context-event persistence, cached-usage event/snapshot preservation, durable cache-observation round trips, and artifact validation. Remaining fault-injection and directory-durability work is tracked as hardening; Phase 3 context is active.
